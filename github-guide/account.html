注册账号与基础设置

有了账号才能创建仓库、提 Issue、参与开源。这一篇带你完成注册、熟悉界面，并把安全设置一次做到位。

注册 GitHub 账号

  1. 打开 github.com/signup。
  2. 填写邮箱（建议使用常用邮箱）、密码（至少 15 个字符，或至少 8 个字符且包含数字和小写字母）、用户名。
  3. 选择所在地区，并选择是否接收产品邮件（可以取消勾选，不影响使用）。
  4. 完成"人类验证"小游戏，然后点击 Create account。
  5. 系统会向你的邮箱发送 6 位验证码，填入后账号即创建成功。
注意

用户名会出现在你的主页地址（github.com/你的用户名）、提交记录和所有协作通知里，而且后续修改会影响旧链接。建议用"姓名拼音 + 有意义后缀"，避免纯数字或过于随意的昵称，将来求职时也方便展示。

用户名的规则

  • 只能包含字母、数字和单个连字符 -，不能以连字符开头或结尾。
  • 最多 39 个字符，不区分大小写（Alice 与 alice 视为同一个）。
  • 已被占用的用户名无法使用；一些保留词（如 admin）也不可选。

选择账号类型

注册时你会被问及账号类型：

  • Personal account（个人账号）：适合绝大多数人，可以创建无限量公开/私有仓库，也可以被加入组织。
  • Organization（组织）：用于团队共管仓库、统一计费与权限。个人账号注册后随时可以再创建组织。

拿不准就选个人账号，之后不影响任何功能。

登录后的界面导览

登录后顶部是一条全局导航栏，主要入口如下：

入口作用
Home / 左上角 GitHub 标志回到个人工作台，查看动态、推荐仓库、最近访问的项目。
Search（或按 /）搜索仓库、代码、Issue、用户。
CopilotAI 编程助手入口（部分地区/账号可用）。
＋ 新建按钮新建仓库、导入仓库、新建 Gist、新建组织、新建 Codespace。
Pull requests / Issues集中查看你参与的评审请求与任务。
铃铛 Notifications通知中心，可设置已读与订阅规则。
头像菜单Your profile、Your repositories、Settings（设置）、Sign out（退出登录）。
提示

按 / 可以直接聚焦搜索框；在任意仓库页面按 t 可以进入"文件模糊查找"模式，输入文件名即可跳转，非常适合浏览大项目。

完善个人资料

头像菜单 → Settings → 左侧 Public profile，可以设置：

  • 头像：建议使用清晰的正方形照片或图形标识。
  • Name：展示名称，可以和用户名不同。
  • Bio：一句话介绍，最多 160 字符，例如"前端工程师 · 正在学习 Rust"。
  • URL / 社交账号 / 公司 / 所在地：会让个人主页更可信。
  • Pronouns：可选的人称代词。

设置完成后，访问 github.com/你的用户名 就是你的公开主页。后续可以在「更多平台功能」里用 README 把主页做得更好看。

安全设置：这三件事请立刻做

1. 开启双重验证（2FA）

GitHub 要求为平台贡献代码的账号启用双重验证。开启后，除密码外还需要一次性验证码，账号被盗的风险大幅降低。

  1. 进入 Settings → Password and authentication。
  2. 点击 Enable two-factor authentication。
  3. 选择 Authenticator app，用手机上的验证器（如 Microsoft Authenticator、Google Authenticator、1Password）扫描二维码。
  4. 输入手机上显示的 6 位数字，确认绑定。
  5. 下载并离线保存恢复码（Recovery codes），手机丢失时用它们登录。
重要

恢复码只显示一次。请打印或存入密码管理器，不要截图后随手丢在相册里。丢失手机又没有恢复码，找回账号会非常麻烦。

2. 保护邮箱隐私

在 Settings → Emails 中勾选：

  • Keep my email addresses private：提交记录中显示 12345678+用户名@users.noreply.github.com 而不是真实邮箱。
  • Block command line pushes that expose my email：防止本地提交时意外泄露邮箱。

3. 检查登录设备

同一个页面下方可以查看 Active sessions，发现陌生设备立即撤销，并建议同时修改密码。

免费账号够用吗

方案适合谁关键限制
GitHub Free个人学习、开源项目公开仓库 Actions 免费；私有仓库每月有免费额度；Pages 仅支持公开仓库
GitHub Pro重度个人开发者更多私有仓库 Actions 分钟数、代码审查工具
GitHub Team小型团队组织级权限、团队评审、项目管理增强
GitHub Enterprise企业单点登录、审计、合规与企业级支持

具体价格与额度以 github.com/pricing 为准。学习阶段用免费版完全足够。
