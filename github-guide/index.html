从零开始，学会用 GitHub

这是一套写给完全新手的 GitHub 中文指南。不需要任何编程基础，也不需要先懂命令行——我们从一个账号开始，一步步走到能独立建仓库、提 Pull Request、用 Actions 自动部署网站。

这套指南讲什么

GitHub 是全球最大的代码托管与协作平台。它不只是一个"放代码的网盘"，而是把版本管理（Git）、团队协作（Issue / Pull Request）、自动化（Actions）、网站托管（Pages）等功能组合在一起的工作平台。

本指南按照"先会用、再理解、最后扩展"的顺序组织，每一页都可以独立阅读，也建议按顺序读完前六篇。

01 概念 什么是 Git 与 GitHub 用仓库、提交、分支这些词，把版本控制讲清楚。 02 入门 注册与账号设置 注册账号、完善资料、开启双重验证，保护账号安全。 03 动手 创建第一个仓库 从网页到本地，完整走通第一次提交与推送。 04 协作 Pull Request 现代软件开发最核心的协作方式：提改动、做评审、合并。 05 自动化 GitHub Actions 让机器替你跑测试、打包、发布，一次配置长期生效。 06 发布 GitHub Pages 把仓库变成可以在手机和电脑上访问的公开网站。

推荐学习路径

  1. 第 1 步 · 建立概念（约 20 分钟）读「什么是 Git 与 GitHub」，搞懂仓库、提交、远程这三个词。
  2. 第 2 步 · 准备环境（约 30 分钟）注册账号并开启双重验证，安装 Git，配置用户名与邮箱。
  3. 第 3 步 · 完成第一次（约 40 分钟）创建仓库，在本地改一个文件，提交并推送上去。
  4. 第 4 步 · 掌握日常操作（约 1 小时）熟悉 status / add / commit / log / pull / push，能自己排查小问题。
  5. 第 5 步 · 学会协作（约 1 小时）新建分支、发 Pull Request、处理评审意见、合并到主分支。
  6. 第 6 步 · 解锁平台能力（按需）按兴趣挑 Actions、Pages、Projects、Copilot 中的任意章节深入。

开始之前，你需要准备什么

  • 一个可以正常收邮件的邮箱（用于注册和找回账号）。
  • 一台能上网的电脑；手机也可以阅读本指南，但动手练习建议用电脑。
  • 不需要编程基础。示例里的代码可以原样复制执行，我们会逐行解释。
  • 不需要付费。本指南涉及的功能（公开仓库、Actions、Pages）都有免费额度。

三个最常见的新手疑问

Git 和 GitHub 是同一个东西吗？

不是。Git 是装在你电脑上的版本控制工具，负责记录文件的每一次变化；GitHub 是一个网站，负责把 Git 仓库放到云端，并围绕它提供协作功能。可以类比成：Git 是 Word，GitHub 是网盘加协同编辑。

一定要背命令吗？

不一定。GitHub 网页版、GitHub Desktop 客户端都能完成大部分操作。但命令行的表达最准确，遇到问题时也最容易被搜到答案。本指南会同时给出"网页操作"和"命令行"两种方式。

免费账号够用吗？

对个人学习完全够用：无限量的公开与私有仓库、每月 2000 分钟的 Actions 免费额度、GitHub Pages 静态站点托管、Copilot 免费额度等。团队协作时再考虑付费方案即可。
